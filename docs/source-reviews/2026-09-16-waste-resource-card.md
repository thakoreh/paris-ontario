# Waste, recycling and disposal resource card source review: 2026-09-16

The resource-hub card is a task-oriented starting point, not a collection-status service. It sends residents to the County of Brant's collection map and item lookup without requesting an address or presenting a Paris Pulse schedule.[1][2]

The card links recycling questions to the official County page, which identifies the current Blue Box contacts and program operators.[3] For furniture or other large household items, it links to the County eligibility page rather than assuming every property qualifies.[5] The Paris transfer-station link deliberately leads to the current official details because the County distinguishes small loads from prohibited large loads and publishes seasonal details there.[4]

## Editorial limits

Paris Pulse does not publish a universal collection weekday, holiday-date calculation, permanent station hours, live opening status, green-bin guidance, or Blue Box availability. Residents must confirm the current details, eligibility, fees and service notices with the official source before acting.
